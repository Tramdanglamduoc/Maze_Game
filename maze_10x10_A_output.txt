======================================================================
Assumptions and Notes
======================================================================
1. S and G are treated as passable cells with numeric value 0.
2. X cells are walls and cannot be entered.
3. For 4-directional movement, the allowed moves are up, down, left, and right.
4. For 8-directional movement, diagonal moves are also allowed and count as one move.
5. Diagonal movement is allowed if the destination cell is inside the maze and not a wall.
6. No additional corner-cutting restriction is applied for diagonal moves.
7. V means the number of passable cells; E means the number of graph edges.
8. The program validates that the maze has exactly one S, exactly one G, valid characters, equal row lengths, and size at most 100x100.

Approach: Dijkstra's algorithm with a binary heap priority queue.
Reason: All cell values and edge costs are non-negative, so Dijkstra correctly finds the minimum-cost path.

Does allowing diagonal movement change the shortest path length? Yes.
4-directional shortest moves = 18; 8-directional shortest moves = 11.
Does allowing diagonal movement change the cheapest path cost? Yes.
4-directional minimum cost = 26; 8-directional minimum cost = 18.
Is the fewest-moves path the same as the cheapest path in 4-directional mode? No.
Explanation: BFS minimizes the number of moves, while Dijkstra minimizes the total cell cost. Therefore, a path with more moves can still be cheaper if it passes through lower-value cells.
Time complexity: BFS is O(V + E); Dijkstra is O((V + E) log V).
Space complexity: O(V) for BFS and O(V + E) for Dijkstra.
